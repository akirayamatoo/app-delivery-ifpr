# App de Delivery - Lanchonete

## O que é
Um aplicativo móvel para gestão e realização de pedidos de lanches, permitindo que os clientes façam pedidos e acompanhem o status da entrega em tempo real, enquanto a lanchonete e os entregadores gerem o fluxo de trabalho.

## Como rodar
Para executar este projeto na sua máquina local, siga os passos abaixo:
1. Clone este repositório na sua máquina.
2. Instale as dependências do projeto executando o comando `npm install` (ou equivalente).
3. Configure as variáveis de ambiente copiando o ficheiro `.env.example` para `.env` e preenchendo os dados do servidor.
4. Execute o projeto localmente com o comando `npm start`.

## Estrutura
O repositório está organizado da seguinte forma para facilitar a manutenção:
* `/src`: Contém todo o código-fonte principal da aplicação.
* `/docs`: Documentação técnica, diagramas UML e registo de decisões.
* `/tests`: Ficheiros de testes unitários e de integração.
* `/assets`: Imagens, ícones e recursos visuais.

## Como contribuir
Para contribuir com o projeto, siga o fluxo abaixo:
1. Crie uma nova *branch* para a sua funcionalidade ou correção de bug.
2. Faça *commits* pequenos, rastreáveis e com mensagens claras explicando o que foi alterado.
3. Se a sua alteração mudar o comportamento do sistema, atualize os ficheiros correspondentes na pasta `/docs` no mesmo *commit*.
4. Abra um *Pull Request* para que o seu código passe por revisão de outro membro da equipa antes de ser integrado.
